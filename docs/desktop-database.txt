THE DATABASE OF THE .EXE   (v23: SQLite)

The data is kept in SQLite, using the sqlite module built into Electron's Node (nothing to install or compile).
The folder is FIXED, %APPDATA%\FleetPilot (not under the app name), so a changed name or ID cannot make it look empty.

WHAT IS IN %APPDATA%\FleetPilot
  databases\     your database(s), one SQLite file each (<name>.db). Pilot > Database chooses which opens at start (default: the last one used).
  copies\        one safety copy per month (first save of the month), and one copy before the data layout is upgraded.
  damaged\       a file that could not be read is moved here, never overwritten.
  old-files\     the .fpdb.json files of v21 and earlier, kept unchanged after their data was moved into SQLite (first start of v23).
  settings.json  which database opens at start.

INSIDE A DATABASE
  meta      format, format version, program version, name, saved at, record count
  fields    every top-level part of the ledger, in order (a list, or a value such as settings)
  records   one row per record: list (vehicles, rentals, payments ...), position, id, the record as JSON
Every save is one transaction: fully written or not at all.

Installing a newer version replaces the program only. An uninstall keeps this folder.
Only one copy of the program can run at a time, so two copies can never write the same database.
Excel stays for import and export only: File & backup > Save database file / Open database file / Import.
To back up by hand: close FleetPilot and copy the .db file.
