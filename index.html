File & backup

Save, update or open your Excel database file.

📊

How should your Excel look?

Select Save database file to choose the sheets, columns and header of your Excel file. Update existing file reuses the layout you saved last.

Excel layout

These choices shape the report sheets, which come first. Your data sheets (the backup) are always saved in full, after the reports. Choices are remembered automatically.

What to save

Everything is saved in one file, as before. Choose a month or a year to make a separate clean file; your working database is not changed and "Update existing file" keeps using the full file.

Tabs and fields in the saved file

Amber = reports, grey = your data. ▲ ▼ move a tab. Vehicles, Drivers, Clients, Bookings and Rentals stay grouped after FuelAccount; Meta and Settings stay last. Untick Show to hide a tab in Excel (it is still saved inside the file, so Open restores everything). Fields chooses which columns show.
